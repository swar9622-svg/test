# الدليل التعليمي الشامل 21.84

هذه نسخة تعليمية تفاعلية فقط من تطبيق كشف المتابعة. لا تعمل كشاشة إدارة عادية أثناء الجولة؛ بل تعرض شرحاً متسلسلاً لجميع الشاشات والوظائف والنوافذ. تظهر يد متحركة على العنصر، وتحاكي الضغط المفرد والضغط المزدوج والضغط المطول والسحب.

تبدأ الجولة تلقائياً، وكل ضغط على بطاقة الإرشاد ينتقل إلى الخطوة التالية حتى نهاية الدليل. تحتوي الحزمة على بيانات وهمية ومكتبات التصدير والصورة وملف manifest.
